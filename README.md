# Проєкт: Аналіз комерційних даних та результатів продажів за 2023 рік

Комплексний аналітичний проєкт, який охоплює весь цикл роботи з даними: від написання оптимальних SQL-запитів для вивантаження інформації до побудови інтерактивних дашбордів у Power BI та формування фінальної аналітичної довідки (бізнес-сторітелінгу з перевіркою гіпотез).

## 🛠️ Технологічний стек
* **SQL (DQL):** агрегація даних, фільтрація, точне групування за унікальним ID клієнта (`customer_id`), розрахунок середніх показників.
* **Power BI Desktop:** моделювання даних, побудова комбінованих візуалізацій, аналіз операційного навантаження.
* **Аналітичний сторітелінг:** формування бізнес-гіпотез на основі обмеженого датасету (1 рік), сезонний аналіз, розробка стратегічних рекомендацій для маркетингу та логістики.

## 📈 Ключові етапи проєкту
1. **Вивантаження та підготовка даних (https://github.com/yuliyasmirnaya2017K/sales-data-analytics-2023/blob/main/script.sql):** Написано 6 оптимізованих SQL-запитів для сегментації продажів за категоріями, продуктами, клієнтами та днями тижня з точним математичним групуванням.
2. **Візуалізація та моделювання (https://github.com/yuliyasmirnaya2017K/sales-data-analytics-2023/blob/main/sales_analysis_dashboard.pbix):** Створено інтерактивний дашборд Power BI, який дозволяє зіставити фінансові результати з фізичними обсягами товарів.
3. **Бізнес-аналіз та гіпотези [(`[Звіт про результати аналізу продажів_смирна.pdf]):](url)** Сформовано підсумковий PDF-звіт, де результати аналізу представлені у вигляді зважених бізнес-гіпотез (вплив промоакцій на волатильність категорій, оцінка утримання VIP-клієнтів).

## 📊 Основні інсайти (Гіпотези для перевірки)
* **Category 2** генерує найбільший виторг, але має високу волатильність (піки в січні та вересні). Висунуто гіпотезу про зв'язок цих коливань із внутрішніми промоакціями.
* Виявлено точні лідери асортименту (**Product B та Product A**) як головні драйвери фізичного обсягу продажів.
* Аналіз помісячних результатів спростував теорію про повну кореляцію виторгу та кількості штук без додаткових математичних розрахунків (фінансовий максимум припав на січень, кількісний — на червень).
* Операційна активність має чіткі піки в середу та п'ятницю, та суттєво просідає в суботу й неділю, що сформувало гіпотези для коригування маркетингового календаря.
